# 审计包与缺口清单

`.audit/` 是生产就绪证据的槽位。正式 GO/NO-GO 报告由 `production-readiness-audit` 写入；本技能只建目录习惯，或在 align-audit 模式输出缺口。

## 槽位（bootstrap）

```text
.audit/
  README.md    # 说明：本目录给审计技能用；不要把营销材料放这里
```

README 写清：默认只读审计；唯一写入是 `.audit/`；P0 未清则 NO-GO。

## align-audit 缺口清单模板

```markdown
# 工程承载面缺口

- 仓库：
- 模式：align-audit
- 当前估计成熟度：L0 / L1 / L2 / 未知
- 建议目标：

| 价值流阶段 | 仓内应对 | 现状（有/无/虚假） | 证据路径 | 建议动作 |
|------------|----------|-------------------|----------|----------|
| 需求 | DoD、产品/需求槽位 | | | |
| 开发 | 骨架、ADR、本地 DX、单测、CI | | | |
| 测试 | 测试入口、guard | | | |
| 验收 | 证据链 | | | |
| 发布 | deploy 契约、verify/rollback、制品分轨 | | | |
| 运营 | 健康/指标槽位 | | | |

## 虚假成熟度（优先拆穿）

- 例如：空 helm、文档承诺 lint 但 CI 未跑、根 tests/ 为空

## 刻意不评

- 业务正确性、功能完整度（除非挡住工程承载）
```

用户要正式审计报告、评分、GO/NO-GO：停止用本技能假装审计完成，改走 `production-readiness-audit`。

## 3. 中文字体设置（关键）

`run.font.name` 只设西文字体；中文需直接改 XML：

```python
rPr = run._r.get_or_add_rPr()
for tag in ("a:latin", "a:ea", "a:cs"):
    el = rPr.find(qn(tag)) or rPr.makeelement(qn(tag), {})
    if el.getparent() is None:
        rPr.append(el)
    el.set("typeface", "微软雅黑")  # 示例字体；实际用项目声明的中文字体
```
字间距：`rPr.set("spc", "200")`（单位 1/100 pt）。

## 4. 图表画法速查（全部原生形状）

| 图 | 画法 |
|---|---|
| 横向流程 | `MSO_SHAPE.CHEVRON` 等宽排列，步长 = 宽+间距；终点项填主色反白 |
| 三列架构 | 三张等高卡 + 列间 `RIGHT_ARROW`(0.4×0.42)；顶部跨列「API/总线」条 |
| 泳道闭环 | 左侧泳道名 chip(1.95 宽) + 每道 3 节点卡 + 小箭头；底部整行 `LEFT_ARROW` 作回流带（文字写进箭头 text_frame） |
| S 形服务链 | 上排左→右 + `DOWN_ARROW` 转折 + 下排右→左；关键节点主色高亮；虚线回流沿卡片外侧走线（三段直线连接器，末段带箭头） |
| 环形飞轮 | `MSO_SHAPE.DONUT`(adj≈0.055) 作细环 或「外浅圆+内挖空」作厚环 + 四象限卡(上下左右偏移 R+0.3) + 中心 `OVAL` + 4 个 `ISOSCELES_TRIANGLE` 放在 45°/135°/225°/315°；旋转按 bearing（自正北顺时针）：x=cx+R·sinθ, y=cy−R·cosθ, rotation=(θ+90)%360，等腰三角默认朝北 |
| 分组色带流程（九步长链） | 三条圆角色带（`rect` `rounded`，ZEBRA/浅主色）作分组背景 + 带内节点卡等距双行文本 + 节点间金色小箭头(`RIGHT_ARROW` ≈0.11×0.18)；关键分组（平台补齐段）节点填主色反白、色带换浅主色调；先画色带再画节点（z-order 自底向上） |
| 层卡架构图（四层栈） | 每层一张宽卡(≈6.9×0.7–0.86)：左侧「层名 11.5pt 粗 + 7.5pt 技术栈」标题列(≈1.55 宽)，右侧层内模块 chip 行（`rect` 白底小圆角，宽 ≈0.96–1.2、gap 0.055，anchor MIDDLE）；层间 `DOWN_ARROW`(0.18×0.2) + 右侧 7.5pt 灰字标注**层间契约**（如「HTTP/REST·JWT」「任务表提交·状态回写」「SQL·S3 SDK」）；深色层的 tech 副标题用 PAPER_TX |
| 三平面部署视图 | 三条横向满宽带卡（控制面/数据面/执行面）纵向堆叠，用深浅色区分平面层级；下方配现网截图证明可运行 |
| 节点内双行文本 | 不用 `\n`（run 内换行不可靠）——循环多段 `para(tf, ln, ...)`，首段 bold、锚点 `MSO_ANCHOR.MIDDLE` |
| 回流虚线（两段式） | 出发点从节点底部中心出发 → 三段直线连接器：下出（无箭头）→ 横走卡片**外侧**空带（无箭头）→ 垂直回到目标节点底部（末段 `arrow=True`）；每段单独一条 `dashed()`；回流标签写在横走段下方 8pt |
| 对比双面板 | 左 ZEBRA 面板(灰标签) + 右主色深底面板(金标签·PAPER_TX 正文)，同维度逐行对仗(rowh ≈0.56，面板 h≈3.6)；中间 30pt 辅助色「≠」居中；底部可加全宽 ZEBRA 数据条 |
| S 形闭环（六段） | 分带眉注两条 9.5pt(左灰/右主色粗)+hairline；上排 3 白节点(3.6×0.92, ①标题11.5pt粗+8.5pt副行) 金 RIGHT_ARROW(0.4×0.34)；下排 3 主色反白节点右→左，灰 LEFT_ARROW；右列行间金 DOWN_ARROW；回流三段走左外侧(x≈0.5)；标签 9pt 居中于第二排下 |
| 关键词卡 | 卡内标题(13–13.5pt) + 题下 0.45×0.028 辅助色短划线；正文/注释 space_before=12 给划线让位，目检确认不压行 |
| 深浅分区三卡 | 核心卡主色深底反白(标题白/正文 PAPER_TX)、其余白卡描边；题下短划线；卡底虚线细线 + 组件 chip 行(等宽 (CW-3×0.16)/4 ≈2.86×0.46, ZEBRA 底主色 10pt 粗居中) |
| 资产飞轮 | 厚环：外圆(浅辅助色 R≈1.5)+内圆挖空(R≈1.14, 页底色)+中心白圆(R≈1.08, 金 1pt 描边, 主题 14pt 粗+9.5pt 副题)；四方位卡 3.1×0.8(N/S)/2.9×0.8(E/W)，N/S 主色、E 浅主色、W 辅助色，标题 12pt 反白+8.5pt 副行；旋转三角 0.26 金色 |
| 全宽结论横幅 | 深主色满宽带(h≈0.56) + 12.5pt 反白加粗居中；位于内容区底≈5.5，每页至多一条 |
| 段带眉注 | 一条 0.75pt 细线；线上方左端 9.5pt 灰标签(通用区)、右端 9.5pt 主色加粗标签(强调区) |
| 时间轴 | 一条 hairline + `OVAL` 场点(关键点填主色) + 标签在上、说明在下 |
| 表格 | 不用真表格：逐格 `rect` 填色（表头主色反白、斑马纹浅米）+ 文本框垂直居中；只留横向分隔感，不画全框线 |
| 对接总线 | 虚线水平连接器 + 一排等宽 chip |
| 占位图 | 白底 + 0.75pt 金色虚线框 + 居中 9.5pt 灰字「配图占位 · 说明（生图）」 |

## 5. 生成后程序化自检（并入 build 脚本末尾）

```python
from pptx import Presentation
chk = Presentation(OUT)
bad = ["椿年", "我方", "贵方", "安防设备"]           # 按项目禁用词替换
blob = "\n".join(sh.text_frame.text
                 for sl in chk.slides for sh in sl.shapes if sh.has_text_frame)
for w in bad:
    assert w not in blob, f"禁用词: {w}"
print("slides:", len(chk.slides._sldIdLst))
```

## 6. 渲染管线细节

`render_check.py` 后端优先级与注意事项：

1. **LibreOffice**：`soffice --headless --convert-to pdf`。跨平台首选；中文需系统装有对应字体。
2. **macOS PowerPoint**：AppleScript 导出 PDF。注意：必须用 `with timeout of N seconds` 包裹；若返回 -9074 说明文档已打开或有模态框，先 `get name of every presentation` 判断再操作；自动化易受对话框干扰，失败重试不超过 2 次，仍失败则降级。
3. **qlmanage**：`qlmanage -t -s 1800 -o dir deck.pptx`，仅能出封面缩略图，只作兜底。

PDF→PNG 统一用 `pypdfium2`（`pdf[i].render(scale=1.4).to_pil().save(...)`），无需系统级 poppler。

## 7. 输出纪律

- 生成文件只写入项目内指定目录，按项目分子目录存放
- 重建方式随交付一并告知（build 脚本留档可复跑）
- 面向客户的成稿不得出现内部卡片 id、目录路径、内部 Q 编号等分析痕迹（除非用户明确要求保留）
